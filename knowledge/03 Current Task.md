# Current Task

Довести три связанных пользовательских сценария FitCRM: визуально выровнять экран подписки,
починить глобальный переключатель RU/UZ/EN и превратить Telegram Mini App в безопасное
ролевое рабочее пространство для владельца и сотрудников, сохранив клиентский кабинет.

## В работе 2026-07-27

- Заменить слишком тёмные «текущего цвета» границы подписки на системный `border-border`.
- Исправить падение меню языка Base UI и привести триггер к компактному виду RU/UZ/EN без иконки.
- После привязки сотрудника назначать персональную кнопку Web App и персональные команды Telegram.
- Резолвить Telegram-актора по актуальной активной staff/client записи, `club_id` и разрешениям;
  не доверять кэшированной роли из `telegram_users`.
- Добавить ролевой bootstrap Mini App: владелец видит KPI клуба, остальные сотрудники только
  разрешённые рабочие блоки; клиентский кабинет остаётся без регрессий.
- Закрыть найденные обходы прав в staff-callbacks и убрать глобальные клиентские команды для
  сотрудников.
- Проверить локально типы, тесты, production build, CRM desktop/mobile и Telegram states; затем
  обновить память, отправить изменения в `main` и проверить production.

## Реализовано локально 2026-07-27

- Экран подписки использует `border-border` и мягкое brand-выделение только текущего тарифа;
  тяжёлые чёрные `currentColor`-границы удалены.
- Меню RU/UZ/EN больше не падает из-за отсутствующего Base UI group context; триггер стал
  компактной текстовой pill без иконки. Все три языка сохранены и проверены в браузере.
- Telegram-актора теперь определяет единый resolver по активной staff/client записи текущего
  `club_id`; роль и permissions каждый раз перечитываются из CRM, неизвестные роли deny-by-default.
- Mini App принимает владельца и сотрудников: владелец видит финансовую и операционную сводку,
  тренер — только своё расписание и разрешённые показатели, остальные роли — ровно те данные,
  которые разрешены их CRM permissions.
- Клиентские команды убраны из global Telegram scope. Уже привязанным пользователям назначается
  персональная Web App кнопка; добавлен безопасный скрипт обновления существующих Telegram-чатов.
- Привязка своего Telegram доступна сотруднику из `/profile` и не требует права управления
  интеграцией клуба; подключение/отключение самого бота остаётся защищено `telegram.manage`.
- Локально прошли TypeScript, focused ESLint, production build, 71 релевантный тест и подписанный
  Mini App API smoke для реального linked owner (`200`, role-aware stats/schedule).
- Финальный security review закрыл три найденных P1: Telegram permissions пересекаются с тарифом,
  Web App кнопка ставится независимо от команд, а ручной `/schedule` тренера фильтруется по нему.
  Повторный review: P0/P1 не осталось.
- Desktop/mobile browser QA экрана подписки и интерактивная проверка RU/UZ/EN пройдены;
  horizontal overflow отсутствует, `design-qa.md`: `passed`.
