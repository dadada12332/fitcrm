# 2026-07-30

## Краткий итог дня

Переключатель языка в верхней панели CRM приведён к более тихому виду. В тарифах добавлен
явный настраиваемый лимит дней заморозки вместо скрытого фиксированного значения. Проведён
полный аудит CRM, Platform Admin, production Supabase и ключевых интеграций; зафиксирован
приоритетный remediation backlog.

## Что было сделано

- Обновлён resting-state кнопки языка в общей `TopBar`.
- Сохранены token-based hover/focus-состояния и доступное имя кнопки.
- Выполнена авторизованная визуальная проверка локального dashboard и сравнение с референсом.
- В создание и редактирование абонемента добавлено числовое поле `Дней заморозки` рядом со
  сроком; `0` отключает возможность заморозки.
- Server Actions проверяют целое неотрицательное значение и не позволяют превысить срок
  абонемента; то же ограничение закреплено Postgres constraint.
- Карточка тарифа показывает точный доступный лимит заморозки.
- Добавлены RU/UZ/EN строки для нового сценария.
- Проведены специализированные owner, staff/RBAC, security, database/RLS, Platform Admin,
  integrations и UX проверки.
- Unit/integration: 164 passed, 1 skipped; Bridge: 41 passed; production build успешен.
- Playwright: 34 passed, 6 skipped, 4 failed из-за cookie banner, перекрывающего нижнюю
  навигацию Telegram Mini App.
- Безопасный two-tenant production test подтвердил базовую RLS-изоляцию; временные QA-данные
  полностью удалены.
- Production Supabase: 71/71 public tables с RLS, но обнаружена критическая возможность
  self-update `users.platform_role` и получения Platform Admin/all-club scope.
- Обнаружен обход биллинга через прямое изменение owner'ом platform-only полей `clubs`.
- Подтверждены риски неатомарных Click/Payme callback, отсутствие рабочей reconciliation и
  recoverable production backup.
- Составлен полный отчёт `FULL_AUDIT_2026-07-30.md` с P0–P2 backlog, module matrix,
  competitor gap и планом 72 часа / 2 недели / 30–90 дней.

## Исправленные ошибки

- Устранена лишняя капсульная обводка вокруг краткого кода языка.
- Устранено скрытое назначение 30 дней заморозки для любого тарифа с включённым переключателем.
- Закрыта self-escalation через `users.platform_role` и wildcard all-club scope.
- Владелец больше не может менять platform-only billing/lifecycle поля клуба через Data API.
- Click/Payme fulfillment стал атомарным и идемпотентным, включая склад и активацию абонемента.
- Индивидуальные права сотрудника применяются в CRM и Telegram.
- Hardware callbacks больше не редиректятся на login до собственной API-key проверки.
- Cookie notice исключён из Mini App; mobile drawers получили focus trap/return и Escape-close.

## Найденные ошибки

- **Внешняя инфраструктура:** ежедневный production backup нельзя запустить без отдельного
  `SUPABASE_DB_URL`, backup passphrase и off-site destination; PITR требует платного решения.
- **P1:** muted-текст имеет недостаточный контраст; RU/UZ/EN остаются частично русскими из-за
  133 жёстких `ru-RU` formatter и всегда русского SSR `lang`.
- Production dependency audit после обновления: 3 high в зависимостях latest stable
  Next.js `16.2.12`; безопасной стабильной версии выше пока нет.
- Полная локализация из пункта 7 аудита намеренно не исправлялась.

## Принятые решения

- Переключатель языка остаётся компактной текстовой кнопкой без постоянного контейнера;
  визуальная обратная связь показывается только при hover/focus.
- Количество дней заморозки является явным лимитом тарифа; ноль означает отсутствие заморозки.
